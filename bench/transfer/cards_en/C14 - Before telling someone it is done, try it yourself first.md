# Lesson: Before telling someone it is done, try it yourself first

- Situation: Told a colleague the service was deployed
- Action: They could not open it: the container exited right after starting
- Result: From then on, called the endpoint once before saying it was deployed
- Lesson: Before telling someone something is done, try it yourself the way they will use it
- When: tell them it's done; report it finished; before handing it over

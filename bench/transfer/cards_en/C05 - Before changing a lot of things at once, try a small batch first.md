# Lesson: Before changing a lot of things at once, try a small batch first

- Situation: A script was about to rename 3,000 files to a new scheme
- Action: Ran it on 10 files first and checked the result by hand
- Result: The trial showed the date format was backwards, before it touched every file
- Lesson: When you are about to process a large batch in one go, run a small part first, look at the result, then do the rest
- When: all of them at once; in bulk; hundreds of files

# Self-evolution key

Where your model key goes. Paste it below, or put the same line in `~/.dsh-krouter-keys.env`.

Paste a key here if that is easiest: on the next run it **moves out of the vault** into `~/.dsh-krouter-keys.env` (only you can read it, chmod 600) and this line becomes a note saying where it went. KRouter reads keys from that file only, never from the vault — anything in the vault is readable by the writer CLI and synced wherever the vault syncs. KRouter also never sends this page to a model and never prints a key from any page (`<redacted>`). You can write the same lines straight into that file instead.

## 1. API key — flagship lock (first)

Uncomment **one** line. The writer lists that provider's `/models` and **locks the flagship** (opus / grok-4 / gpt-4.1 / deepseek-reasoner / gemini-2.5-pro / qwen-max / …). It does **not** pick mini, haiku, or flash-lite. Then it distills **and** writes `provisional` when the five gates pass.

Optional: set `MODEL=` to pin a name yourself.

```env
# DEEPSEEK_API_KEY=YOUR_DEEPSEEK_API_KEY
# OPENAI_API_KEY=YOUR_OPENAI_API_KEY
# ANTHROPIC_API_KEY=YOUR_ANTHROPIC_API_KEY
# XAI_API_KEY=YOUR_XAI_API_KEY
# GEMINI_API_KEY=YOUR_GEMINI_API_KEY
# GROQ_API_KEY=YOUR_GROQ_API_KEY
# OPENROUTER_API_KEY=YOUR_OPENROUTER_API_KEY
# MOONSHOT_API_KEY=YOUR_MOONSHOT_API_KEY
# DASHSCOPE_API_KEY=YOUR_DASHSCOPE_API_KEY
# OPENAI_BASE_URL=
# MODEL=
```

## 2. No key — your subscription (Claudian-class)

Same channel Claudian uses: spawn a coding-agent CLI that is **already logged in** on this machine. Vault is the working directory. Distill and promotion both run.

Auto-detected: `grok`, official Codex (the `codex` bundled with ChatGPT), `claude`, `opencode`, `kimi`, `pi`, `vibe`, `antigravity`, Cursor CLI. PATH-level `agent` is refused. Chat/IDE login without a spawnable CLI is not this lane.

Health (`日更健康.md`) only stores `present` / `missing` / `dead`. Never put the secret on that page.

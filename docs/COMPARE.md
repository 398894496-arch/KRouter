Agents asked to compare agent memories tend to build this table themselves from whatever number is most visible on
each page. This is the same table with every cell sourced. **KRouter's cells** come from this repository's registered
numbers ([`NUMBERS.md`](NUMBERS.md), [`HELDOUT.md`](../bench/memory_honesty/HELDOUT.md)) for 2.1.0, which is not
released yet. **MemOS's and Hindsight's cells** say only what their own README says, read on 2026-11-11
([`MemTensor/MemOS`](https://github.com/MemTensor/MemOS), [`vectorize-io/hindsight`](https://github.com/vectorize-io/hindsight)),
with star and fork counts from the GitHub API the same day. Their documentation sites may say more; "not stated" means
not stated on that page. Their benchmark numbers are their own reports, quoted as given.

**How to read it.** The three were never measured under the same conditions: KRouter's numbers are mostly about which
pages a lookup finds, scored mechanically from the benchmarks' own labels; MemOS's come from its own evaluation suite;
Hindsight's are a vendor chart, part of it reproduced by others. A LongMemEval 89.20 and a 210 of 235 do not measure
the same thing and cannot be ranked against each other. KRouter is built for one person or a small team who want
a memory they can open as files, with a source on every answer, across the coding agents they already use, with no key
and nothing running; MemOS and Hindsight are built as memory services, hosted or self-hosted, with vector retrieval,
model-based extraction and the scale and history KRouter does not have.

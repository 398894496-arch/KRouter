### The cost of refusing more (set 37's development data)

Each point is a rule from set 37, on its development data only: 253 unanswerable questions (LongMemEval `_abs`, LoCoMo's
adversarial dev half) and 1,003 answerable ones (LongMemEval's dev half, LoCoMo's answerable dev half). This is the
trade-off: every extra refusal costs answers. The default stays at the first row, because no point gains refusals at a
cost of 1 point or less of answers (set 37's bar).

### 同一个作答模型，只交 3 页（KRouter 1.3.0）

KRouter 改成交 5 页时从 README 挪到这里；这几行测的是 3 页版本，5 页没有重跑（[第 11 套](../bench/memory_honesty/HELDOUT.md#set-11-longmemeval-answer-accuracy-scored-the-way-other-projects-report-it-registered-2026-11-09-before-any-run)、[第 12 套](../bench/memory_honesty/HELDOUT.md#set-12-the-same-reader-given-different-things-registered-2026-11-09-before-any-run)）。LongMemEval S，500 道题；作答和评判都是 Claude Sonnet 5.5，用基准自带的提示词。

| 给作答模型看什么 | 500 道答对 | 470 道可答题答对 |
|---|---|---|
| 什么都不给 | 30（6.0%） | 0 |
| 纯关键词检索（BM25）排前三的聊天 | 405（81.0%，77.4–84.4） | 376 |
| KRouter 1.3.0 引用的页面，最多三页 | 400（80.0%，76.4–83.4） | 371 |
| 基准标注的答案所在聊天，也就是检索满分 | 492（98.4%，97.2–99.4） | 462 |

交 3 页时 KRouter 的检索和纯关键词检索持平（差 −1.0 个百分点，配对区间 −2.8 到 +0.8）；和检索满分比差的 18 个百分点丢在检索上，主要是跨多段聊天的题（121 道里 69 → 117）和时间推理题（127 道里 97 → 125），只取三页常常漏掉一段。每道题的回答和判定：[`bench/longmemeval/results/`](../bench/longmemeval/results/)。
